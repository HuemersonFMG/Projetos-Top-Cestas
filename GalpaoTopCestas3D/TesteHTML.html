Sobre o Projeto

Este é um modelo 3D interativo do Galpão Top Cestas, criado com Sweet Home 3D. Você pode visualizar o projeto de diferentes ângulos, ajustar a iluminação e explorar os detalhes do design.

Use os controles ao lado para navegar pelo modelo. Arraste para rotacionar a vista, use a roda do mouse para zoom in/out e os botões para alternar entre diferentes modos de visualização.

Como Hospedar seus Arquivos no GitHub

1 Criar uma conta no GitHub

Se você ainda não tem uma conta, acesse github.com e crie uma conta gratuita.

2 Criar um novo repositório

Após fazer login, clique no botão "+" no canto superior direito e selecione "New repository".

Dê um nome ao seu repositório (por exemplo: "meu-projeto-3d"), marque a opção "Public" e clique em "Create repository".

3 Preparar seus arquivos

Não é necessário compactar os arquivos em ZIP. Você pode enviar os arquivos individualmente:

  • Arquivo OBJ do seu modelo
  • Arquivo MTL (materiais)
  • Arquivos de textura (JPG, PNG, etc.)
  • Arquivo HTML (esta página)

Certifique-se de que todos os arquivos estejam na mesma pasta ou mantenha a mesma estrutura de pastas do seu projeto.

4 Fazer upload dos arquivos

No seu repositório, clique no botão "Add file" e selecione "Upload files".

Arraste os arquivos para a área indicada ou clique em "choose your files" para selecioná-los.

Adicione uma mensagem de commit (por exemplo: "Adicionar arquivos do projeto 3D") e clique em "Commit changes".

5 Ativar o GitHub Pages

No seu repositório, clique na aba "Settings" (configurações).

No menu lateral, clique em "Pages".

Em "Source", selecione a branch "main" e a pasta "/ (root)" e clique em "Save".

Aguarde alguns minutos e aparecerá um link para sua página hospedada (algo como: https://seuusuario.github.io/meu-projeto-3d/).

6 Obter URL direta para os arquivos

Para obter a URL direta de um arquivo, clique no arquivo no repositório e depois no botão "Raw".

A URL na barra de endereços será a URL direta para o arquivo. Remova o prefixo blob/ se existir.

Exemplo de URL: https://raw.githubusercontent.com/seuusuario/meu-projeto-3d/main/modelo.obj

7 Usar no visualizador 3D

Copie a URL do arquivo OBJ e cole no campo "URL do arquivo .OBJ" no visualizador.

Clique em "Carregar Modelo" para visualizar seu projeto 3D.

Dicas Importantes

Estrutura de Arquivos

Mantenha todos os arquivos relacionados (OBJ, MTL, texturas) na mesma pasta para evitar problemas de carregamento.

Se estiver usando texturas, verifique se os caminhos no arquivo MTL estão corretos.

Limitações do GitHub

O GitHub tem um limite de 100MB para arquivos individuais. Se seu modelo for maior, considere usar outra plataforma como Dropbox ou Google Drive.

As atualizações podem levar alguns minutos para ficarem disponíveis.
